# Polices auto-hébergées

- Cormorant Garamond, graisses 600 italique et 700, latin, WOFF2 ; paquet `@fontsource/cormorant-garamond` 5.3.0.
- Work Sans, graisses 400, 500 et 600, latin, WOFF2 ; paquet `@fontsource/work-sans` 5.3.0.

Les deux familles utilisent la SIL Open Font License 1.1 (`OFL-1.1`).
Les licences complètes et leurs mentions de copyright sont conservées à côté des fichiers.
Les fichiers proviennent des paquets Fontsource verrouillés dans `package-lock.json`.
Aucune requête vers un fournisseur de polices distant n’est nécessaire.
